# JS (gbk) vs Swift song renders

Generated by `scripts/compare-gbk/run` (CI job `parity-gbk`, gated with `COMPARE_GATE=1`). Each song's MIDI file is
converted to a `sf2-parity-render` scenario (`midi-to-scenario.py`: channel events at sample frames, programs from the
SoundFont, effects + master bus on, 256 voices, end = last event + 3 s, long files cut at 45 s with CC123/CC64 off),
rendered offline at 44.1 kHz by gbk's JS `Sf2SynthEngine` with its default settings (`gbk-render.mts`) and by this
package's `sf2-parity-render`, and compared by `metrics.py` (difference RMS relative to the JS render, difference
peak, correlation, BS.1770 integrated loudness, end of the audible tail at -60 dB re peak, and 5-band spectral
level difference, Swift minus JS). SoundFont: GeneralUser GS (gbk `public/static`). Songs: gbk's stored song
`songs/2026-10-23-midnight-invention` plus three MIDI files from gbk `public/static`. ("Neon Overpass" is not in the
gbk repository; songs created in the app are stored server-side.)
